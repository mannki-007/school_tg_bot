## ЧТО ЭТО?

  Это телеграмм бот созданный для простой автоматизации школьных чатов. 
  Например,учитель написал что-то важное и потом это потерялось в флуде и на следующий день в школе тебя наругали за то что ты не прочитал что-то важное.
  Для того чтобы такие ситуации не случались я сделал этого бота.

![Меню бота](https://github.com/user-attachments/assets/f1c61e23-2e76-4ba1-8a5e-659347150051)

  
## Как этим пользоваться?
  Функции меню:
  * /menu - вызвать меню
  * Расписание - узнать расписание 
  * ДЗ - узнать Д/З
  * ВАЖНОЕ - посмотреть важные новости для класса
  * Мероприятия - узнать есть ли актуальные мероприятия для класса
  * История ДЗ -  просмотреть 5 последних записанных в память Д/З 
  * ПОМОЩЬ!! - открывает меню помощи

## Как что-то записать?
  * !расписание <..>- записывает расписание. Просмотреть пример можно,написав !расписание
  * !мероприятие <..> - записывает мероприятиею. Просмотреть пример можно,написав !мероприятие
  * !важное <..> - записывает важную информацию. Просмотреть пример можно,написав !важное
